# Calculator

A responsive calculator built with **HTML, CSS, and JavaScript**.

## Features

- Addition, subtraction, multiplication, and division
- Percentage calculations
- Square root
- Clear (`AC`) and backspace (`C`)
- Keyboard input, Enter to calculate, and Escape to clear
- Responsive dark theme
- No libraries, build tools, or installation required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser, or use the **Live Server** extension in VS Code.
3. Use the calculator.

## Deploy with GitHub Pages

1. Create a new repository on GitHub.
2. Upload the files in this folder to the repository's root.
3. Open **Settings → Pages**.
4. Under the build/deployment section, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site; the URL will appear in the Pages settings.

## Project files

- `index.html` — page structure and calculator buttons
- `style.css` — responsive styling and dark gradient theme
- `script.js` — calculator behavior
- `.gitignore` — ignores common local/editor files
